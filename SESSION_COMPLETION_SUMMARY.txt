## How It Works

### User Perspective
1. User logs in
2. Selects entity (MAIN, TRADIFY-001, or Pristing-Planet-001)
3. Session stores selected_entity_id
4. All views automatically filter by that entity
5. User sees only data for selected entity
6. Switching entities updates all views instantly

### Technical Implementation
1. SessionEntityMixin imported in all views
2. View class inherits: `class MyView(SessionEntityMixin, LoginRequiredMixin, View)`
3. Mixin's `dispatch()` method validates entity selection
4. Mixin's `get_queryset()` filters by entity_id
5. Mixin's `get_context_data()` passes entity info to templates
