# Theme Switching System - User Guide

## 🎨 What is Theme Switching?

The Theme Switching System allows you to change your entire TradifyERP appearance while keeping ALL your data and functionality intact. It's like redecorating your office without moving anything!

## 🚀 How to Switch Themes

### 1. Go to Theme Settings
- Click **🎨 Themes** in the navigation menu
- Or visit: `/accounting/theme/settings/`

### 2. Browse Available Themes
You'll see theme cards showing:
- Theme name
- Description
- Preview color
- Current active theme (marked with ✓)

### 3. Switch Theme
- Click **"Switch Theme"** button on the theme you want
- Page will reload with new theme applied
- Success message confirms change

### 4. Customize Layout (Optional)
After switching, customize your layout:

**Sidebar Color**
- ☀️ Light Sidebar - Bright, modern look
- 🌙 Dark Sidebar - Reduces eye strain, professional feel

**Layout Mode**
- 📊 Vertical Layout - Traditional sidebar on left
- ↔️ Horizontal Layout - Top navigation bar

**Container Width**
- 📱 Fluid Width - Uses full screen width
- 📦 Boxed Width - Fixed width container

## 💾 Your Settings Are Saved

Once you switch themes or change layout settings:
✅ Settings are saved to your account
✅ Settings persist across logins
✅ Each user has their own preferences
✅ Your data remains completely intact

## ❓ FAQ

**Q: Will switching theme delete my data?**
A: No! Your data is 100% safe. Only the visual appearance changes.

**Q: Can I switch themes frequently?**
A: Yes! Switch anytime without any impact.

**Q: Do all users see the same theme?**
A: No! Each user has their own preference. Your choice doesn't affect others.

**Q: Can I use different themes on different devices?**
A: Yes! Set your preference on each device independently.

**Q: What if my organization wants everyone on the same theme?**
A: Contact admin - they can set default themes for teams.

**Q: Can I create my own theme?**
A: Contact your system administrator - they can add custom themes.

**Q: Will theme switching slow down the system?**
A: No! Switching is instant and doesn't affect performance.

**Q: Can I revert to the original theme?**
A: Yes! Go back to Theme Settings and select the original theme.
