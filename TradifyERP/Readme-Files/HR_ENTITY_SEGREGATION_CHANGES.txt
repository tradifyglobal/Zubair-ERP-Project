ENTITY FILTER PATTERNS:

Pattern 1: Direct Entity Field (7 models)
  Models: Department, Position, Employee, Payroll, Benefit, Leave, Attendance
  Implementation:
    def get_queryset(self):
        queryset = super().get_queryset()  # SessionEntityMixin handles filtering
        # Add additional filtering
        return queryset

Pattern 2: Entity Through Employee Relationship (8 models)
  Models: Attendance*, PayrollRecord, SalaryHistory, EmployeeBenefit, 
          LeaveBalance, LeaveRequest, Disciplinary, Performance
  Implementation:
    def get_queryset(self):
        entity_id = self.request.session.get('selected_entity_id')
        queryset = ModelName.objects.filter(employee__entity_id=entity_id)
        # Add additional filtering
        return queryset
  
  (*Note: Attendance has BOTH direct and through patterns)
