## How It Works (For Each Updated Module)

1. **User selects entity** → Session stores `selected_entity_id`
2. **View inherits SessionEntityMixin** → Automatic dispatch check
3. **Mixin validates entity** → Redirect if not selected
4. **get_queryset() called** → Mixin filters by entity_id
5. **Template receives context** → Entity info passed to HTML

**Result**: Users only see data for their selected entity ✅
